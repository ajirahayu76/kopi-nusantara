# Salam Kopi - Kedai Kopi & Specialty Coffee Nusantara

Website resmi **Salam Kopi Indonesia** (https://ajirahayu.ai.studio/). Platform katalog kopi nusantara, manual brew, keranjang belanja, checkout QRIS, kasir (POS), dasbor finansial kafe, serta dukungan penuh **Mode Gelap (Dark Mode) & Mode Terang (Light Mode)**.

Dibuat dengan ❤️ untuk pecinta kopi Nusantara.
